      What you are looking at

      The training is real

      A multi-layer perceptron with a tanh hidden layer and a softmax output, trained with cross-entropy. Each worker rebuilds the dataset from its seed, takes only its own shard, runs the forward and backward passes, and returns the mean gradient and loss over those samples. The An node combines the shards weighted by sample count — which is the mean gradient over the whole dataset — and takes one step of gradient descent. With the shipped defaults it reaches about 99% accuracy on data it never trained on.

      The arithmetic is the same arithmetic. A test in this repository runs 40 epochs across four shards and 40 epochs on one machine and asserts the parameter vectors agree: sharding changes the message flow, not the model.

      The failures are real

      A delivery stays unacknowledged until a worker has published its reply. Stop a worker mid-round and the broker puts everything it was holding back on the queue for whoever is still alive — the round finishes late instead of never. Stop all of them and the queue grows while the An node sits at n/4 gradients, because a round that never receives a full set never closes.

      The principals run an actual Raft: randomized election timeouts, the up-to-date check on votes, log matching, and commitment by majority. Stop two of three and the survivor campaigns forever without ever winning, which is why the deployment guide tells you to run an odd number.

      What is simulated

      The broker is a model of RabbitMQ's dispatch, acknowledgement and requeue behaviour, not RabbitMQ. Consensus is a compact Raft rather than openraft over sled. There is no database, no JWT, and no TLS on this page; encryption at rest is reported in the log, not performed.

      Time is scaled so a packet is visible: links carry about 45ms of latency and a shard takes tens of milliseconds to compute, against a 400ms epoch. The shipped configuration dispatches every 100ms onto a local broker, where a round closes long before the next one starts.

      Where each piece lives

        Served as a static page — no backend, no build step, no network calls after load. The simulation is a port of the Rust crate it ships with; the dataset and the initial weights are checked against values printed by that crate on every run of the test suite.
